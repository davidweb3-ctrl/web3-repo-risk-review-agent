# Demo Script

Target length: about 3 minutes.

## 1. Problem

AI agents and developers can ship repository changes that affect Web3 value movement: contract approvals, payment limits, autonomous execution, withdrawal accounting, and release automation.

## 2. Project

Web3 Repo Risk Review Agent turns GitLab repository context into actionable release guidance.

## 3. Demo Flow

1. Select the agent payment merge-request scenario.
2. Show the risk score and `block release` decision.
3. Open findings for unlimited approval, policy-limit changes, auto-execution, CI release automation, and missing tests.
4. Show proposed GitLab MCP actions: label the merge request, create a review comment, and open a release-blocking issue.
5. Switch to the vault withdrawal scenario and show accounting/withdrawal-risk coverage.
6. Switch to the docs-only scenario to show a low-risk path.

## 4. Close

This is not a formal audit replacement. It is a fast agentic review layer that helps Web3 teams catch obvious release risks before production.
